# 📲 Añadir ArroyoBus a la pantalla de inicio

Aunque ArroyoBus es una web, puedes instalarla en tu móvil como si fuera una aplicación nativa. Así la tendrás siempre a mano desde la pantalla de inicio, sin necesidad de abrir el navegador.

## 🍎 iPhone (Safari)

{% stepper %}
{% step %}
## Abre **Safari** y escribe en la barra de búsqueda: `arroyobus.net`
{% endstep %}

{% step %}
## Una vez dentro de la web, pulsa el botón blanco **"Abrir app"**.
{% endstep %}

{% step %}
## La primera vez, la app te pedirá **aceptar los permisos de ubicación**. Acéptalos para una mejor experiencia.
{% endstep %}

{% step %}
## En el menú de Safari situado debajo de la URL, pulsa el icono **Compartir** 🔗.

{% hint style="warning" %}
**iOS 26**: si tienes el sistema actualizado, primero pulsa los **3 puntos (···)** y después **Compartir**.
{% endhint %}
{% endstep %}

{% step %}
## Desplázate por las opciones hasta encontrar **"Añadir a pantalla de inicio"** ➕.
{% endstep %}

{% step %}
## Se abrirá una ventana emergente. Pulsa el botón **"Añadir"** (esquina superior derecha, en azul).
{% endstep %}

{% step %}
## ¡Listo! Ya tienes ArroyoBus instalado en tu iPhone. 🎉
{% endstep %}
{% endstepper %}

## 🤖 Android (Chrome)

{% stepper %}
{% step %}
## Abre **Chrome** y escribe en la barra de búsqueda: `arroyobus.net`
{% endstep %}

{% step %}
## Una vez dentro de la web, pulsa el botón blanco **"Abrir app"**.
{% endstep %}

{% step %}
## La primera vez, la app te pedirá **aceptar los permisos de ubicación**. Acéptalos para una mejor experiencia.
{% endstep %}

{% step %}
## Pulsa los **3 puntos horizontales (⋮)** situados en la esquina superior derecha del navegador.
{% endstep %}

{% step %}
## En el menú desplegable, localiza y pulsa **"Añadir a la pantalla de inicio"**.
{% endstep %}

{% step %}
## Se abrirá una ventana emergente con el título **"Crear acceso directo"**. Pulsa **"Añadir"** (esquina inferior derecha).
{% endstep %}

{% step %}
## ¡Listo! Ya tienes ArroyoBus instalado en tu dispositivo Android. 🎉
{% endstep %}
{% endstepper %}
